## Proyecto Destacado: [SCARI](https://github.com/villaralan11/scari)

**Sistema de Clasificación Automática de Residuos Inteligente**

Un basurero inteligente que clasifica residuos en **orgánicos** e **inorgánicos** usando visión por IA — construido con ESP32-S3, ESP32-CAM y Groq API.

| | |
|---|---|
| **IA** | llama-4-scout-17b-16e-instruct vía Groq API (gratis) |
| **Visión** | ESP32-CAM → UART → ESP32-S3 (JPEG en tiempo real) |
| **Actuación** | Motor NEMA 17 + driver A4988 (perfil trapezoidal) |
| **Retroalimentación** | LED RGB nativo (WS2812) en GPIO48 |
| **Portal** | Servidor web async con dashboard en vivo + API JSON |
| **Firmware** | Arduino IDE, FreeRTOS, buffer circular |

**Dashboard Features:**
- Estadísticas en tiempo real (orgánico / inorgánico / desconocido)
- Gauge de precisión + barras de distribución
- Historial completo con timestamps relativos
- Portal cautivo (sin internet necesario)
- API REST (/status, /historial, /reset)

> _"El usuario solo tira el residuo — SCARI detecta, clasifica y lo ordena solo."_
